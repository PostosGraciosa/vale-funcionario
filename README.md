# Sistema de Emissão de Vales - Vale Funcionário


## 📌 Sobre o projeto

Sistema web desenvolvido para emissão, impressão e controle de vales para funcionários da Rede Postos Graciosa.

O objetivo é substituir processos manuais, criando um documento padronizado com:

- Dados da empresa
- CNPJ automático
- Identificação do funcionário
- Valor do vale
- Motivo
- Número sequencial do vale
- Declaração para assinatura



## 🚀 Funcionalidades atuais

### Emissão de Vale

✅ Seleção da empresa  
✅ Preenchimento automático do CNPJ  
✅ Data automática  
✅ Numeração automática do vale  
✅ Cadastro do funcionário  
✅ Informações do motivo  
✅ Geração de documento para impressão  


### Impressão

✅ Layout A4  
✅ Logo da empresa  
✅ Declaração automática  
✅ Campo para assinatura do funcionário  
✅ Campo para assinatura do responsável
